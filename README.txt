PORTFOLIO BENZAHRA HOUSSAM

1. Ouvrir index.html dans un navigateur pour prévisualiser le site.
2. Ajouter votre CV PDF dans ce dossier sous le nom: cv.pdf
3. Remplacer les blocs "Image projet 01..." par vos images de projets.
4. Remplacer les liens LinkedIn/Behance et les liens "Voir le projet".
5. Pour publier le site, téléversez le dossier sur un hébergeur statique.

Le site est responsive (ordinateur + mobile) et ne nécessite aucune bibliothèque externe.
